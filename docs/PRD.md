## 1. 项目概述

### 1.1 背景与目标

呼吸训练是气功、冥想、减压中的基础练习。市面工具要么参数固定、要么需要联网注册，缺少"**简单、可自定义、本地运行、带音效引导**"的呼吸训练管理器。

**MVP 目标**：用户在浏览器中打开应用，选择呼吸模式（硬气功），设定吸气 / 屏息 / 呼气 / 休息时长，在音效与文字引导下完成呼吸训练，并实时看到完成的周期数量。

### 1.2 目标用户

- 硬气功 / 气功练习者
- 冥想、减压、睡眠引导需求人群

### 1.3 产品形态

- **平台**：Web 单页应用（SPA），浏览器打开即用，零安装、零后端。
- **设备**：桌面浏览器 + 移动端浏览器（响应式适配）。
- **音效**：Web Audio API 实时**合成**呼吸音效，无外部音频文件依赖。

## 2. 版本范围

### 2.1 MVP 范围（本版必做）

| 编号 | 范围 |
|---|---|

| S2 | 吸气 / 屏息 / 呼气 / 休息四段时间的自定义设置 |
| S3 | 吸气、屏息、呼气、休息四相位呼吸引导（文字 + 合成音效 + 休息提示） |

- 真人录音音效、语音播报（TTS）
- 用户系统、云端同步、社交分享
- 生物传感器联动

## 3. 功能需求

### FR-01 呼吸模式选择

- **描述**：用户可从模式列表中选择呼吸模式。MVP 仅提供"硬气功"模式；模式提供一组**推荐默认时长**，用户仍可自由修改。
- **验收标准**：
  1. 页面可见模式选择控件，MVP 至少有"硬气功"一项；
  2. 选择"硬气功"后，时长设置自动填入推荐默认值（见 FR-02）；
  3. 模式数据以可扩展结构存储（数组/对象），新增模式无需改动核心逻辑。

### FR-02 时长设置

- **描述**：用户可分别设置**吸气时长、屏息时长、呼气时长、休息时长**。
- **范围与默认值**：

| 参数 | 范围 | 步进 | 硬气功推荐默认 |
|---|---|---|---|
| 吸气时长 | 1 ~ 60 s | 1 s | 2 s |
| 屏息时长 | 1 ~ 60 s | 1 s | 20 s |
| 呼气时长 | 1 ~ 60 s | 1 s | 10 s |
| 休息时长 | 0 ~ 60 s | 1 s | 20 s |

> 注：硬气功推荐默认值（吸 2 / 屏 20 / 呼 10 / 休 20）**已确认**，后续可调；调整时同步更新本文档。

- **验收标准**：
  1. 四个时长均可独立调整，非法输入（越界/非数字）被拒绝并回显有效值；
  2. **运行中修改即时生效**：修改立即应用于后续相位（当前正在进行的相位不中断，从下一个相位起使用新值）；空闲时修改同样生效。

### FR-03 呼吸引导（四相位）

- **描述**：训练开始后，按 **吸气 → 屏息 → 呼气 → 休息** 循环推进，每一相位均有明确的视觉与听觉提示。
- **相位定义**：

| 相位 | 视觉提示 | 听觉提示 |
|---|---|---|
| 吸气（INHALE） | 大号文字"吸气"+ 剩余秒数 | 合成吸气音效（渐强） |
| 屏息（HOLD） | 大号文字"屏息"+ 剩余秒数 | 静音（无呼吸声），切换时轻提示 |
| 呼气（EXHALE） | 大号文字"呼气"+ 剩余秒数 | 合成呼气音效（渐弱） |
| 休息（REST） | 大号文字"休息"+ 剩余秒数 | 柔和"叮"提示音 + 文字提示"请休息" |

- **验收标准**：
  1. 相位严格按 吸 → 屏 → 呼 → 休 顺序推进，每个相位持续时间为对应设置值；
  2. 相位切换瞬间（误差 ≤ 100ms）视觉与音效同步切换；
  3. 休息时长 = 0 时跳过休息相位，呼气结束后直接进入下一周期吸气；休息时长 > 0 时，休息计时完成后才进入下一周期。

### FR-04 音效提示

- **描述**：吸气、呼气使用合成音效模拟呼吸声；屏息相位静音；休息使用提示音。所有音效可**静音/调节音量**。
- **合成方案**（详见 §5）：白噪声 + 带通滤波，通过包络（渐强/渐弱）区分吸气与呼气。
- **验收标准**：
  1. 吸气相位播放吸气音效，呼气相位播放呼气音效，屏息相位静音，休息相位播放提示音；
  2. 相位结束时音效自然淡出，无爆音（click/pop）；
  3. 提供音效开关与音量滑块（0~100%），关闭后训练全程无声音。

### FR-05 休息提示

- **描述**：休息相位必须明确提示"休息"，与吸/呼的引导音区分。
- **验收标准**：休息相位显示"休息"字样与剩余秒数，并播放区别于呼吸声的提示音。

### FR-06 周期统计

- **描述**：**吸气 + 屏息 + 呼气 + 休息 = 1 个周期**。实时统计并展示本次会话完成的周期数量。
- **验收标准**：
  1. 周期数 +1 时机：休息时长 > 0 时在休息相位结束 +1；休息时长 = 0 时在呼气相位结束 +1（一个完整吸屏呼[休]循环 = 1 周期）；
  2. 统计在界面持续可见（如"已完成 N 个周期"）；
  3. 停止/重置后归零，暂停不丢失当前进度；
  4. 周期数在长时间运行下计数准确（用时间戳驱动，不用累加器）。

### FR-07 训练控制

- **描述**：提供 **开始 / 暂停 / 继续 / 停止** 控制。
- **验收标准**：
  1. 空闲态：显示"开始"；
  2. 运行态：显示"暂停"与"停止"；
  3. 暂停后计时冻结，恢复后从暂停点继续（而非重来）；
  4. 停止后回到空闲态，周期统计归零；
  5. 控制切换无音频残留（暂停/停止时立即淡出当前音效）。

## 4. 交互设计

### 4.1 页面结构（文字线框）

```
│  Breath Timer  呼吸训练管理器      │  ← 标题栏
├─────────────────────────────────┤
│  模式：[硬气功 ▼]                  │  ← 模式选择（下拉/标签）
├─────────────────────────────────┤
│  ┌───────────────────────────┐  │
│  │      吸 气                 │  │  ← 主引导区：当前相位
│  │       2.0 s                │  │    大号文字 + 剩余秒数
│  │   ◯ 环形进度               │  │
│  └───────────────────────────┘  │
├─────────────────────────────────┤
│  吸气时长  [-] 2s [+]            │  ← 设置区（运行中也可编辑，即时生效）
│  屏息时长  [-] 20s [+]           │
│  呼气时长  [-] 10s [+]           │
│  休息时长  [-] 20s [+]           │
├─────────────────────────────────┤
│  [ ▶ 开始 ]  [ ⏸ 暂停 ] [ ⏹ 停止 ]│  ← 控制区
│  音效 [🔊 80%]                  │
├─────────────────────────────────┤
│  已完成周期：12   ·   总用时 1:24  │  ← 统计区
└─────────────────────────────────┘
```

### 4.2 状态机

```
        ┌────────────┐
        │   IDLE     │  ← 空闲（初始/停止后）
        └─────┬──────┘
              │ 开始
        ┌─────▼──────┐   暂停    ┌─────────┐
        │  RUNNING   │◄─────────►│ PAUSED  │
        └─────┬──────┘   继续    └─────────┘
              │ 停止
        ┌─────▼──────┐
        │  IDLE      │  （统计归零）
        └────────────┘
```

RUNNING 内部相位流转：

```
INHALE ──► HOLD ──► EXHALE ──► REST ──► INHALE …
（周期 +1：休息 > 0 时在 REST 结束 +1；休息 = 0 时跳过 REST，在 EXHALE 结束 +1）
```

### 4.3 交互细节

- 训练运行中：设置区**可编辑且即时生效**（当前相位不中断，从下一相位起用新值；见 FR-02）；
- 主引导区颜色随相位变化（吸=青蓝、屏=紫、呼=橙、休=灰绿），并兼顾色弱用户（文字标签始终显示）；
- 移动端支持振动提示（navigator.vibrate）作为音效的补充（可选，默认开启、可关）。

## 5. 音效设计（Web Audio 合成）

### 5.1 合成原理

| 相位 | 声源 | 滤波 | 包络 |
|---|---|---|---|
| 吸气 | 白噪声 | 带通 ~600 Hz（Q≈1.2） | 渐强（attack 占相位 20%），结束前淡出 |
| 屏息 | 静音（可加极轻持续底噪，待试听） | — | — |
| 呼气 | 白噪声 | 带通 ~350 Hz（Q≈1.0） | 渐弱（release 占相位 30%），自然收尾 |
| 休息 | 正弦波 880 Hz + 谐波 | — | 短促 120ms，"叮" |

> 呼吸声本质是宽带噪声经声道滤波，白噪声 + 带通滤波是轻量且真实的近似；具体中心频率/包络参数以听感调优为准（§11 待试听）。

### 5.2 参数可调性

- 音效参数集中在一个配置对象中（`audioConfig`），便于试听调优；
- 音量滑块作用于总输出 GainNode（0~100%）；
- 静音开关 = 总 Gain 置 0 + 停止调度。

### 5.3 浏览器自动播放策略（重要）

- 浏览器禁止无用户手势播放音频：**AudioContext 必须在用户点击"开始"时创建/恢复**（`ctx.resume()`）；
- 应用在首屏提供一次交互（点击开始）即满足策略；音频调度基于**当前时间轴**（`ctx.currentTime`），避免 setInterval 漂移。

## 6. 数据模型

```js
// 设置（持久化：localStorage，键 bt_settings_v1）
Settings = {
  mode: 'qigong-hard',          // 当前模式 id
  inhaleSec: 2,                 // 吸气秒数
  holdSec: 20,                  // 屏息秒数
  exhaleSec: 10,                // 呼气秒数
  restSec: 20,                  // 休息秒数
  volume: 0.8,                  // 0~1
  muted: false,
  vibrate: true,
}

// 模式定义（可扩展数组，MVP 仅一项）
Mode = {
  id: 'qigong-hard',
  name: '硬气功',
  defaults: { inhaleSec: 2, holdSec: 20, exhaleSec: 10, restSec: 20 },
  hint: '吸气短促，屏息蓄劲，呼气缓慢',  // 可选提示语
}

// 运行时状态（不持久化）
SessionState = {
  status: 'IDLE' | 'RUNNING' | 'PAUSED',
  phase: 'INHALE' | 'HOLD' | 'EXHALE' | 'REST',
  phaseRemainMs: 0,             // 当前相位剩余毫秒
  phaseEndAt: 0,                // 相位结束时间戳（Date.now()，驱动计时）
  cycleCount: 0,                // 已完成周期数
  startedAt: 0, elapsedMs: 0,   // 会话用时
  pausedAccumMs: 0,             // 暂停累计，用于精确恢复
}
```

## 7. 技术方案

| 项 | 决策 |
|---|---|
| 技术栈 | 原生 HTML5 + CSS3 + ES Modules JavaScript；**无框架、无构建步骤** |
| 音频 | Web Audio API（AudioContext / NoiseBuffer / BiquadFilter / GainNode） |
| 持久化 | localStorage（仅保存设置） |
| 兼容性 | 现代浏览器：Chrome / Edge ≥ 90，Firefox ≥ 95，Safari ≥ 15（移动端同源） |
| 模块划分 | `app.js`（装配/UI 绑定）、`stateMachine.js`（纯逻辑状态机）、`timer.js`（时间戳计时）、`audio.js`（合成音效）、`settings.js`（设置读写）、`ui.js`（DOM 渲染） |

**核心设计原则**：
1. **计时用时间戳驱动**（`phaseEndAt = Date.now() + duration`），渲染循环用 `requestAnimationFrame` 或 100ms 轮询取差，杜绝 setInterval 累加导致的漂移；
2. **纯逻辑与 DOM/音频分离**：`stateMachine.js`、`timer.js` 不依赖浏览器 API，可在 Node 中直接单元测试；
3. 所有音频调度基于 `AudioContext.currentTime` 时间轴，暂停 = 停止调度 + 记录剩余。

## 8. 非功能需求

- **性能**：空载 CPU 占用可忽略；长时间训练（≥1h）无内存泄漏（音频节点用后关闭）；
- **可访问性**：相位文字对比度 ≥ WCAG AA；支持键盘操作（Tab + Enter）；`aria-live` 播报相位切换；
- **移动端**：竖屏适配；大按钮（≥44px 触控区）；可选振动反馈；
- **可靠性**：页面意外关闭不损坏 localStorage；恢复打开保留上次设置。

### 9.1 单元测试（自动化，Node 内置 test runner `node --test`）

| 模块 | 覆盖点 |
|---|---|
| `stateMachine.js` | 状态合法流转（IDLE→RUNNING→PAUSED→…）；非法流转拒绝；相位顺序 吸→屏→呼→休 循环；周期 +1 时机 |

| `audio.js` | 参数生成（包络时长、滤波频率、音量映射）；静音时零输出；节点生命周期（stop 后清理） |
